# Woolworths Loyalty KPI Reward Program – Power BI Dashboard

## Project Overview
This project involves developing an interactive Power BI dashboard to analyse the Woolworths Loyalty KPI Reward Program. The dashboard presents key performance indicators and visual insights to support business performance monitoring and analysis.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualisation

## Key Features
- Interactive KPI cards
- Loyalty programme performance analysis
- Location-based drill-down analysis
- Business performance visualisation
- Interactive reporting

## Business Objectives
- Monitor loyalty programme KPIs.
- Analyse performance across locations.
- Present business insights through interactive dashboards.
- Support data-driven decision-making.
